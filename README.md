# Vat exercises

Two short exercises about a farm's milk vat. Use whichever language you prefer: Python, TypeScript or PHP.

1. **Live coding:** `milkings/<language>/`. We'll work through it together; start with its README.
2. **Code review:** `review/<language>/`. Start with its README, which describes the change.

## What you need

- **Python:** 3.10 or later, and `pytest` (or `uv`)
- **TypeScript:** Node.js 20 or later
- **PHP:** 8.1 or later and Composer, or Docker

The live coding tests fail with "not implemented" until you write the code. That's expected.

This repository is shared with other candidates, so please don't open issues or leave comments here.
